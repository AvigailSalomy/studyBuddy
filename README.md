# StudyBuddy

StudyBuddy is a web application for university students to find, create, and manage study groups.

The platform allows users to discover relevant groups, send join requests, share study materials, communicate through group chat, schedule meetings, and manage group tasks.

## Tech Stack

- Next.js
- TypeScript
- Supabase
- Tailwind CSS
- Vercel

## Getting Started

Install the dependencies:

npm install

Create a `.env.local` file based on `.env.local.example` and add the required environment variables.

Run the development server:

npm run dev

Then open http://localhost:3000.
